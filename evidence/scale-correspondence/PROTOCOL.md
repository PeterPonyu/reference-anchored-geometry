# Frozen scale and row-correspondence sensitivity protocol

Written before computing the new results, 2026-09-21. This is a descriptive extension of a measurement study using frozen saved computational objects. It is not a prospective biological registration or a model comparison.

Select exactly 24 stored objects by filename and historical configuration, never by score: four backgrounds (setty, dentate, endo, lung), seeds 0/1/2, native simplex Topic alpha=1 K=10 and continuous DPMM mixture_weight=1 K=50. Each object retains its native/continuous declaration, byte hashes, test indices, and matched archived 50-PC reference. Both object types contain ten coordinates. No training is performed and no relative method superiority is estimated. This distributed protocol uses semantic object descriptions; the scientific selection and computation rules are unchanged.

Scale analysis: each of 24 objects at k=5,15,30 crossed with the first 10,25,50 columns of its existing 50-PC reference; 216 complete batteries. The PCA is not refitted and is the historical transductive reference. Report reachability, edge survival, separation, and native-only exact coherence; no combined score. Compare each score to its own k15/PC50 baseline and summarize descriptive ranges across the nine settings. No independent biological units are created by graph or rank choices.

Correspondence analysis: the 12 native objects, k15/PC50, fractions 0,.1,.25,.5,1 and corruption seeds 0,17,42; 180 batteries. Select the first floor(f*n) entries of one fixed RNG permutation, and cycle their row assignments. Thus every selected row is changed for m>=2, preserving the allocation marginal distribution exactly; nested selected sets have different cycles. Record actual changed fraction. The zero fraction is repeated per corruption seed but not treated as extra replication. Report each object's curve and background averages. A mean response need not imply monotonicity of each object.

Implementation controls: for all 24 objects at k15/PC50, rotate/rescale candidate coordinates and jointly permute reference/candidate rows; 48 further batteries compared to existing baselines. Geometry should be isometry-invariant absent nearest-neighbour ties; native allocation identity is not preserved by arbitrary coordinate rotation, so check geometry only for that control and set already_simplex=False. Joint row reorder uses unchanged explicit semantic type and also checks coherence. Keep failures/tie discrepancies visible. Full computation count 444; 0 optimizer updates. CPU thread ceiling2. Outputs under this paper's own evidence folder, including full input arrays and executable local scorer snapshot.

Figures: graph-scale/reference-rank sensitivity, and row-correspondence corruption response are separate scientific questions. All figure text pure black; only data marks encode color. No p values, BH, confidence intervals, or biological closure claim.
